# Claude-Next

A modern AI chat template built with Next.js, inspired by Claude's clean and minimalist interface. It provides a solid foundation for building AI-powered chat applications with authentication, streaming responses, file attachments, and markdown support.

## Features

* Claude-inspired chat UI
* Real-time streaming responses
* Google OAuth with NextAuth
* File attachment support
* Markdown and code block rendering
* Responsive design

## Tech Stack

* Next.js 16
* React 19
* Tailwind CSS 4
* shadcn/ui
* NextAuth v5
* Google Gemini

## Getting Started

```bash
pnpm install
pnpm dev
```

Create a `.env.local` file:

```env
GOOGLE_CLIENT_ID=...
GOOGLE_CLIENT_SECRET=...
GOOGLE_GENERATIVE_AI_API_KEY=...
NEXTAUTH_SECRET=...
```

Perfect for developers looking to kickstart AI chat applications with a modern UI, authentication, and streaming AI integration already set up.
